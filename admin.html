Facebook Sharing

Quando pubblichi un post, puoi scegliere di aprire automaticamente il dialogo di condivisione Facebook. Questo apre una finestra in cui puoi aggiungere un tuo commento e condividere il link del post sulla tua bacheca.

Come funziona: ogni post ha il bottone "Condividi su Facebook" che apre la finestra di condivisione nativa di Facebook. Non serve nessuna app o permesso aggiuntivo.

Apri automaticamente il dialogo Facebook ad ogni nuova pubblicazione

Questo URL verrà incluso nei link condivisi su Facebook.

GitHub / Pubblica

Sincronizza i contenuti su GitHub Pages.

Configurazione Repository

Inserisci le credenziali del tuo repository GitHub. Il token viene salvato solo nel browser (localStorage) e non viene mai inviato a terzi.
Per creare un token: GitHub → Settings → Developer Settings → Personal Access Tokens → Tokens (classic) → seleziona permesso repo.

Il token viene salvato solo nel tuo browser, non viene mai inviato ad altri server.

Pubblica su GitHub

Clicca il bottone per caricare tutti i contenuti (post, libri, immagini incluse) su GitHub come file data.json. Il file sarà accessibile pubblicamente da index.html.
